# 新安高中部光伏月度填报自动化系统产品上下文

## 产品愿景

为运维部门建立一套可复用的月度填报自动化流程，先跑通新安高中部单站点，再逐步扩展到更多光伏项目站点。

系统要把每月收到的电网/结算来源文件转成可校验的结构化数据，并自动写入既有 Excel 模板，减少人工抄数、月份错位、公式漏改和重复核对成本。

## 目标用户

- 运维部门成员：每月收集 3 份来源文件，完成学校用电统计表和汇总表填报。
- 运维管理人员：确认当月填报是否成功，查看异常字段和复核提示。
- 财务或结算协同人员：核对电量、电价、电费和汇总金额是否与来源文件一致。

## 首期站点

- 站点名称：新安高中部
- 项目名称：新安中学（高中部）光伏发电项目
- 当前项目目录：`深圳新安中学高中部650KW分布式光伏项目`
- 当前样例月份：`2026-05`

## 核心业务流程

```text
用户放入当月 3 份来源文件
  -> 文件扫描与分类
  -> PDF/图片页面预处理
  -> OCR/文档解析
  -> 字段映射为月度业务数据
  -> 业务规则校验
  -> 写入学校用电统计表月份副本
  -> 写入汇总表格月份副本
  -> 输出 recognized_data.json、validation_report.json 和 process_log.txt
```

## 本地 MVP 必做范围

- 支持新安高中部站点配置。
- 支持扫描指定项目目录并识别 3 类来源 PDF。
- 支持图片型 PDF 渲染为页面图片。
- 支持 OCR 原始结构 JSON 和统一业务字段 JSON。
- 支持必填字段、发电量、消纳电量、金额和月份校验。
- 支持写入 2 个 Excel 结果副本，不覆盖原始模板。
- 支持 strict/review/manual 的基本阻断和复核策略。
- 支持 2026 年 5 月样例重复回归。

## 当前扩展阶段

- MVP-018 与 MVP-019 已完成 OpenClaw WebChat 的任务创建、三份 PDF 收取、受控 Worker 调用、状态查询、字段级复核和两份 Excel 输出闭环。
- MVP-020 正在把同一受控能力接入企业微信智能机器人测试入口。
- 当前企业微信方案固定为官方 `@wecom/aibot-node-sdk@1.0.7` WebSocket 长连接，不使用 URL 回调、Token、EncodingAESKey、公网域名或隧道。
- MVP-020 Phase 1 只实现独立 WeCom channel、可信身份/session 映射、离线测试和一条真实文本健康验证；附件、任务、复核和 Excel 回传在后续 Phase 单独验收。

## 关键业务原则

- 原始模板永不覆盖，只输出月份结果副本。
- 字段识别结果必须先校验，不能直接写入。
- Excel 格式优先保持原样，只写必要单元格和目标行。
- 固定业务参数配置化，例如新安高中部基础电价 `0.6998`。
- 识别模块必须可替换，下游统一消费业务字段 JSON。
